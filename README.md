# EPMS - Employee Performance Management System

A modern Employee Performance Management System (EPMS) built with React, Vite, Tailwind CSS, Node.js, Express, and MongoDB Atlas.

## Features

### Authentication & Security

* Secure Login & Logout
* Role-Based Access Control
* JWT Authentication
* Protected Routes

### Employee Management

* Add Employees
* Edit Employee Information
* Delete Employees
* Employee Profiles
* Department Assignment

### Performance Management

* Performance Reviews
* KPI Tracking
* Goal Management
* Performance Reports
* Employee Evaluation

### Dashboard & Analytics

* Real-Time Dashboard
* Employee Statistics
* Performance Charts
* Activity Monitoring
* Monthly Reports

### Reports

* Employee Reports
* Performance Reports
* Department Reports
* Export to PDF
* Export to Excel

### Notifications

* Performance Review Reminders
* System Notifications
* Task Updates

## Technology Stack

## Installation

### Clone Repository

```bash
git clone https://github.com/Mordekai32/epms.git
cd epms
```

### Install Frontend Dependencies

```bash
npm install
```

### Start Frontend

```bash
npm run dev
```

### Install Backend Dependencies

```bash
cd server
npm install
npm run dev
```
